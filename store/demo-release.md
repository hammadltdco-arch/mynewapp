# Loop Chat — Android demo

Publisher: NovaPulse Digital LLC

This APK is for trying the interface before live Supabase setup is complete.

- Android 7.0 (API 24) or newer
- App name: Loop Chat Demo
- Package: com.novapulsedigital.loop.demo
- Debug-signed test build, separate from the production app
- Chat navigation, local text messages, emojis, and photo attachments
- Messages and photos stay on the device
- Sample contacts and statuses are demonstration data
- No real accounts, live message delivery, or calls
- Not a Google Play production release

Download the APK asset below on your Android device, then open it to install. Android may ask you to allow installs from the browser or file manager you used.

Build, APK signature, and packaged web interaction checks passed. Native installation/startup and live backend acceptance checks are not claimed as completed for this release.
